# Original AnyLogic ICU Model

- **File:** `ICU_Capacity_Model.alp` (original academic team source)
- **Project:** Hospital ICU Simulation & Predictive Modeling
- **Project authors:** Andre Kurniawan and project partner (collaborative academic work)
- **Format:** AnyLogic `.alp` project, saved with AnyLogic 8.9.4.

## How to open

1. Install a compatible version of AnyLogic.
2. Open `ICU_Capacity_Model.alp` from AnyLogic.
3. Review the agent flow, capacity assumptions, resources, and experiments.

## Important: 3D resources

The model references Collada files under relative paths such as `3d/bed.dae` and `3d/nurse.dae`. Those assets were supplied in a separate `separate_3d_assets.zip` within the original user archive but are **not included here** because the license/provenance was not established. AnyLogic may show missing visual objects or warnings until those assets are restored in the expected `3d/` folder. If you own the rights to all 3D files or have redistribution permission, you can add an `anylogic/3d/` folder with the source assets extracted from your personal archive.

This model is a historical educational project and was **not run or verified** for this GitHub packaging step. Do not use it for clinical decisions. Do not add patient-level input data to a public repository.
